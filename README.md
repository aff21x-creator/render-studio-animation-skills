# Render Studio Animation Skills

A reusable Agent Skill for generating deterministic, import-ready animation projects for Personal Animation Render Studio V1.

## Included skill

- `render-studio-animation/` — complete skill package with `SKILL.md`, detailed references, single-file and multi-file examples, and a validation script.

## Install

Use an Agent Skills-compatible client. The Vercel Skills CLI can discover skills in this repository:

```bash
npx skills add https://github.com/aff21x-creator/render-studio-animation-skills
```

See `render-studio-animation/README.md` for the complete package overview and validation instructions.
